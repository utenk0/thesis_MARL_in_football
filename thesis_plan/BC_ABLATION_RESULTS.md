# BC label audit and observation ablation

Date: 3 October 2026

## Purpose

The initial 61-feature BC pilot obtained about 92.6% test action accuracy, but
the observation contains the previous action and the frame-level labels are
highly persistent. This experiment tests whether the score represents learned
football decisions or mostly action repetition. It also tests whether inverse-
frequency loss weighting can recover rare actions.

These results use the bounded `training_stage_v2` clips: six training matches,
two validation matches, two test matches, and 511 joint transitions per match.
They are diagnostic results, not the final thesis comparison.

## Action-label audit

The training split contains 67,452 player-level examples but only 14 of the 19
GRF actions. Five actions have no training examples:

- long pass;
- shot;
- sprint;
- release sprint;
- sliding.

Four event-related actions are present but extremely sparse: high pass has 9
training examples, short pass 8, dribble 2, and release dribble 3. The test
split's 172 “rare” samples consist almost entirely of 166 release-direction
labels; it contains only three high-pass and three short-pass labels.

The previous-action baseline reaches 92.17% ordinary test accuracy and 69.43%
balanced test accuracy. This proves that action persistence is a much stronger
baseline than the majority-class baseline for these frame-level trajectories.

The complete generated audit is in
`artifacts/bc_action_audit_20261003/ACTION_AUDIT.md` when artifacts are present
locally.

## Controlled BC results

Every configuration uses the same two-layer shared actor, optimiser settings,
10 epochs, three seeds, and fixed train/validation/test split. Feature ablations
zero excluded fields while retaining the common 61-dimensional interface.

| Configuration | Retained information | Test accuracy | Test balanced accuracy | Rare-action accuracy |
|---|---|---:|---:|---:|
| Spatial | Current positions/context only | 0.1038 ± 0.0021 | 0.0632 ± 0.0010 | 0.0000 |
| Temporal context | Spatial + causal velocities + possession | 0.1190 ± 0.0096 | 0.0718 ± 0.0032 | 0.0000 |
| Full | Temporal context + previous/sticky actions | 0.9259 ± 0.0001 | 0.6983 ± 0.0001 | 0.0000 |
| Full balanced | Full + capped inverse-frequency loss | 0.9083 ± 0.0081 | 0.6846 ± 0.0084 | 0.0252 ± 0.0055 |

The full model exceeds the previous-action baseline by only about 0.42
percentage points in ordinary accuracy and 0.40 points in balanced accuracy.
It never predicts a test rare action. Class weighting causes some
release-direction predictions, but still learns neither pass class present in
the test split and reduces movement accuracy. The class weights cannot
compensate for only 2–9 training examples.

## Decision

Do not start expensive seven-method training on the current bounded clips.
The next data build must first:

1. cover substantially longer match segments or complete matches;
2. store per-sample label provenance (`tracking_inferred` versus
   `event_override`, including the source event identifier);
3. report action support before training and reject splits whose evaluated
   actions are absent or severely under-supported in training;
4. decide whether unsupported GRF buttons should be excluded from the learned
   action space or generated by a defensible mapping;
5. repeat the BC sanity check before launching PPO, GAIL, CQL, DT, ghosting, or
   CTDE comparisons.

The previous action can remain in the observation because it is causal and
sticky controls require history, but every result must be reported beside the
previous-action baseline. For a decision-focused secondary metric, evaluate
only action-change/event timesteps as well as all frames.

## Data-identity correction (4 October 2026)

The earlier `training_stage_v2` audit exposed two conversion defects rather
than an absence of tackles and Sample Game 3 passes in the source data:

1. Dataset A `TacklingGame` records identify both participants through
   `Winner`/`Loser`, `WinnerTeam`/`LoserTeam`, and their roles. The action actor
   is now the participant with role `withoutBallControl`, irrespective of who
   won the duel.
2. Metrica Sample Game 3 tracking positions are now joined to the real player
   IDs declared by the active FIFA EPTS `DataFormatSpecification`. The mapping
   changes at substitution boundaries; synthetic `*_slot_XX` identities are no
   longer used.

The corrected data was rebuilt separately as `training_stage_v3`, so the v2
diagnostic remains reproducible. Sliding support changed from `0/0/0` to
`5/2/1` for train/validation/test. Sample Game 3 now contributes eight
short-pass labels, increasing test short-pass support from 3 to 11. All ten v3
NPZ files pass the 61-feature observation-contract validator.

This does not solve the broader coverage problem. Long pass, shot, sprint, and
release sprint remain absent from the bounded training clips. The original
decision to delay expensive full-method training therefore still stands.

The corrected audit is generated at
`artifacts/bc_action_audit_v3_20261004/ACTION_AUDIT.md`.
